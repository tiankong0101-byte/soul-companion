## 心理学参考资料

### 心理急救原则（CPR）
- **C**alm（保持冷静）：陪伴者先稳住自己
- **P**诚（真诚倾听）：不评判，真诚回应
- **R**恢复（赋能）：帮助对方找到自己的力量

### 非暴力沟通（NVC）四步
1. 观察（不带评判地描述事实）
2. 感受（说出自己的感受）
3. 需求（说出背后的需求）
4. 请求（提出具体请求）
